# Banking Transaction ETL Pipeline

## Project Overview
A Python-based ETL pipeline that extracts, cleans, transforms, and loads synthetic banking transaction data into a PostgreSQL database.

## Technology Stack
- Python
- Pandas and NumPy
- PostgreSQL
- SQLAlchemy
- Streamlit
- Matplotlib and Seaborn
- Git and GitHub
- Render

## Project Modules
1. Data Extraction
2. Data Cleaning and Transformation
3. Database Integration
4. SQL Analysis and Reporting
5. Interactive Dashboard
6. Deployment

## Data Privacy
This project uses synthetic banking data and does not contain real customer financial information.
